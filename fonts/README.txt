The OFL expressly permits hosting the font files on your own web server,
which is what this site does. Keep this notice and OFL.txt alongside the
font files.

Only the Latin character set is included, to keep the download small.
Both files are variable fonts, so every weight comes from one file:
Montserrat (Light, Regular, Medium) and Bodoni Moda Italic (Regular).

Brand guidelines, edition 01: Montserrat Light for headlines and reading,
Montserrat Medium for small capital labels; Bodoni Moda Italic for quotes,
pull-outs and numerals only.
